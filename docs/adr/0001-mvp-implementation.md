# ADR-0001: MVP реализация пайплайна мониторинга и прогноза

## Статус
Принято.

## Контекст
Нужен запускаемый MVP в локальном окружении с поддержкой:
- захвата кадров,
- подсчёта машин,
- записи 5-минутных метрик,
- обучения и инференса прогноза,
- ручного управления камерами и ROI.

## Решение
1. Использовать FastAPI как единый сервис API + scheduler.
2. Использовать PostgreSQL через SQLAlchemy для хранения справочников, метрик и прогнозов.
3. Реализовать capture/vision/features/forecast в виде отдельных модулей.
4. Запускать jobs через APScheduler:
   - capture/extract: каждые 5 минут,
   - inference: каждые 10 минут,
   - retrain: раз в сутки.
5. Для MVP использовать CPU-friendly модель прогноза (RandomForestRegressor) и baseline fallback.

## Последствия
- Плюсы: быстрый запуск, простая эксплуатация локально, модульная структура.
- Минусы: не выделены отдельные сервисы по процессам; для прод-скейла потребуются worker-процессы и отдельный оркестратор.
