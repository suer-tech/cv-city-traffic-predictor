# ADR-0002: Усиление MVP до функционального приложения

## Статус
Принято.

## Контекст
Каркас MVP требовал доведения до состояния полноценного приложения: идемпотентные записи,
ручное управление маршрутом, реальный UI, ручной запуск jobs и интеграция внешнего факта.

## Решение
1. Добавить idempotent-upsert для метрик и прогнозов в репозитории.
2. Добавить маршруты (`routes`) и API для настройки состава камер маршрута.
3. Добавить Admin UI на корневом URL с операциями управления и просмотром данных.
4. Добавить внешнюю evaluation-интеграцию как non-blocking provider stub.
5. Добавить ручные API для запуска джобов (`/jobs/*`) и dashboard summary.
6. Добавить capture provider switch (`playwright`/`synthetic`) c fallback.

## Последствия
- Плюсы: система пригодна для ежедневной эксплуатации и проверки в локальном контуре.
- Минусы: для production требуется разделение процессов API/worker и полноценные миграции Alembic.
